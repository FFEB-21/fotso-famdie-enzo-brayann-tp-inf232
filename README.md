## Déploiement sur Streamlit Cloud

1. **Fork** ce dépôt sur GitHub
1. Aller sur [share.streamlit.io](https://share.streamlit.io)
1. Connecter votre compte GitHub
1. Sélectionner ce dépôt, branche `main`, fichier `app.py`
1. Le nom de l’app : `fotso-famdie-enzo-brayann-tp-inf232`
1. Cliquer **Deploy**

Le lien généré sera de la forme :

```
https://fotso-famdie-enzo-brayann-tp-inf232-<hash>.streamlit.app/
```

## Lancer en local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Technologies

- Python 3.11
